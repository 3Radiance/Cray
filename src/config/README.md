# config

Оркестратор. Читает конфиг и раздаёт настройки всем модулям. Сам ничего не вычисляет и не проверяет — только дёргает нужные ниточки.

## Ответственность

- Парсинг YAML-конфига (транспорт, протокол, auth, fingerprint)
- Парсинг и валидация Protocol DSL (структура полей, goto-граф без циклов)
- Резолв имён верификаторов/генераторов через `auth::registry`
- Передача TLS/HTTP2/TCP профилей в `fingerprint`
- Регистрация протоколов из `protocol/`
- Сборка транспортного конвейера по конфигу (`tcp → tls → http | http2 | кастомный`)

## Семантический валидатор DSL

При загрузке конфига проверяет:
- Нет циклических `goto` переходов
- Все `verify:` имена существуют в реестре `auth`
- Типы полей корректны
- Предупреждения: слабая энтропия (magic < 4 байт и т.д.)

## Зависимости

```
config → auth        (резолв верификаторов)
config → fingerprint (TLS/HTTP профили)
config → protocol    (регистрация протоколов)
config → transport   (сборка конвейера)
```

## Что модуль НЕ делает

- Не знает про крипто — вся логика в `auth`
- Не держит runtime-состояние соединений
- Не обрабатывает трафик
