# transport/tcp

Точка входа всего транспортного конвейера. Единственный модуль который создаёт сокет — никто другой этого не делает.

## Ответственность

- Принимает входящее TCP-соединение (listener)
- Читает сырые байты
- Передаёт соединение следующему слою по цепочке

## Цепочка

```
tcp → tls → [http | http2 | кастомный транспорт юзера]
```

Какой именно следующий слой — определяется конфигом, не хардкодом внутри модуля.

## Что модуль НЕ делает

- Не знает про TLS, HTTP, протоколы
- Не знает про auth и структуру пакетов
- Не принимает решения про маршрутизацию
