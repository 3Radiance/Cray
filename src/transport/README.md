# transport

Модуль транспорта — конвейер слоёв. Каждый слой получает на вход что дал предыдущий и передаёт следующему.

## Принцип работы

Цепочка собирается по конфигу. Юзер описывает какие слои использовать и в каком порядке — `transport` собирает pipeline и запускает его. Никто из слоёв не знает про других, зависимость только через конфиг.

```
tcp → tls → [http | http2 | кастомный транспорт]
              ↑
         выбирается из конфига
```

## Слои

- **tcp/** — точка входа. Создаёт сокет, читает байты, передаёт дальше по цепочке.
- **tls/** — принимает сокет, оборачивает в `SslStream<TcpStream>`, делает upstream acceptor и хендшейк. Всегда отдаёт `SslStream<TcpStream>`.
- **http/** — HTTP/1.1 труба. Выставляет/удаляет нужные хедеры, байты проходят насквозь.
- **http2/** — HTTP/2 труба. Принимает зашифрованный сокет, настраивает клиент, пакует/распаковывает фреймы.
- **[кастомный]** — юзер пишет свой транспортный слой, собирает бинарник, указывает его в конфиге — встаёт в цепочку как влитой.

## Модульность

Добавить кастомный транспорт = написать реализацию трейта + указать в конфиге. Остальные слои не трогаются.
