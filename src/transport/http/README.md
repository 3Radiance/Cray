# transport/http

HTTP/1.1 транспортный слой. Труба — данные проходят насквозь, модуль занимается только хедерами.

## Ответственность

- Принимает `SslStream<TcpStream>` от `tls/`
- Выставляет нужные HTTP-хедеры (по конфигу)
- Удаляет лишние хедеры которые не должны светиться
- Прозрачно пробрасывает payload дальше в `protocol/`

## Что модуль НЕ делает

- Не разбирает содержимое пакета
- Не знает про auth, HMAC, протоколы
- Не принимает решения "свой/чужой"
