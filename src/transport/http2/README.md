# transport/http2

HTTP/2 транспортный слой. Принимает зашифрованный сокет, поднимает HTTP/2 соединение, пакует/распаковывает фреймы.

## Ответственность

- Принимает `SslStream<TcpStream>` от `tls/`
- Настраивает HTTP/2 клиент с параметрами из `fingerprint` (window size, header table, и т.д.)
- Выполняет HTTP/2 хендшейк (SETTINGS, PREFACE)
- Пакует исходящие данные во фреймы DATA
- Распаковывает входящие фреймы и отдаёт payload в `protocol/`

## Что модуль НЕ делает

- Не создаёт TLS-соединение (это `tls/`)
- Не знает про auth, HMAC, структуру протокола
- Не принимает решения "свой/чужой"
