# fingerprint/tls

Создаёт TLS acceptor (серверная сторона) и connector (клиентская сторона) с нужными настройками из конфига.

## Ответственность

- Принимает TLS-профиль из `config`
- Собирает `SslAcceptor` для серверной стороны
- Собирает `SslConnector` для клиентской стороны
- Настраивает: версии TLS, cipher suites, ALPN, session tickets, curves

## Что отдаёт

- `SslAcceptor` → идёт в `transport/tls/` для входящих соединений
- `SslConnector` → идёт в `transport/tls/` для исходящих соединений

## Что модуль НЕ делает

- Не устанавливает соединения сам
- Не делает хендшейк — только собирает конфигурацию
