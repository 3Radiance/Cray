# Security Policy

## Reporting a Vulnerability

Found something broken or exploitable? Open a GitHub issue:

**[Report an issue](https://github.com/3Radiance/Cray/issues)**

Please include:

- the version or commit hash of Cray you tested;
- the config (with any secrets removed) that reproduces the issue;
- steps to reproduce and, if possible, a minimal test case;
- your assessment of the impact.
